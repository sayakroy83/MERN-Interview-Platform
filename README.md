# MERN Interview Platform

A full-stack coding interview platform built using the MERN stack.  
It allows users to practice coding challenges and conduct one-on-one live technical interviews with an integrated video call and collaborative code editor.

## 🚀 Features
- User signup & login  
- Real-time video call for interviews  
- Collaborative coding pad  
- Coding challenges with code execution  
- Clean and responsive UI  
- Separate frontend and backend setup

## 🧱 Tech Stack
**Frontend:** React, Clerk Auth  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Video & Real-time-chat:** Stream / Socket  

## 📁 Project Structure
MERN-Interview-Platform/
│── Frontend/
│── Backend/
│── README.md


## 🔧 Setup

### Backend
cd Backend
npm install
npm run dev

### Frontend
cd Frontend
npm install
npm run dev

▶️ Usage --->
1) Sign up or log in.
2) Start or join an interview.
3) Use the built-in video call + code editor.
4) Practice coding problems.
